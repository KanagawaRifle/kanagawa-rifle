# 数式の利用

AIが扱う医療データの解析には統計学的なモデルが欠かせません。  
例えば揚力の計算に使われる式をサンプルとして示します[^Yamada]。

$$
L = \frac{1}{2} \rho v^2 S C_L
$$

ここで、

- $$L$$ : 揚力
- $$\rho$$ : 空気密度
- $$v$$ : 速度
- $$S$$ : 翼面積
- $$C_L$$ : 揚力係数

# React 18の新機能（プログラミング例）

技術記事としては、フロントエンドのサンプルコードを載せることも多いです。

```jsx
import { useState } from 'react';

export const Counter = () => {
  const [count, setCount] = useState(0);

  return <button onClick={() => setCount(count + 1)}>Count: {count}</button>;
};
```

このコンポーネントは、React 18の基本機能を示すシンプルな例です。  
また、バックエンドやスクリプト言語の例を載せることもできます。

```python:analysis.py
def analyze_data(data: list[int]) -> float:
    total = sum(data)
    return total / len(data)

```
